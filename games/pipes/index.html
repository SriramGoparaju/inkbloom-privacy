Pipes

Join every pair. Fill every square.

Each colour appears twice on the board. Lay a pipe between every pair so that pipes never cross and every square is covered. Each pair also has its own symbol, so you never have to rely on colour alone.

How to play

  • ●●Drag from one marker to its twin to lay a pipe between them.
  • ✕Pipes never cross. Draw through one and it gives way from there.
  • You've finished when every square is covered. Tap a marker to clear its pipe.

Tips and tricks

  1. Start with the forced ones. Pairs that sit next to each other, or run along the same edge, usually have only one sensible route.
  2. Hug the walls. Pipes along the border and around corners leave the middle open for everyone else.
  3. Don't wall off a pocket. Every square must be filled. If a pocket can only be reached by one colour, that colour has to wind through it.
  4. Take the only step. If a marker has just one free neighbour, its pipe must start there.
  5. One answer. Every board has exactly one solution. If you hit a dead end, an earlier pipe has taken the wrong route.

Where to find it

It takes its turn on the daily page alongside five other rotating games, and the Library always has Easy, Medium and Hard tracks of it. Stuck? A hint costs ink drops, and Inkbloom Plus makes hints unlimited.
